这两天看了一下smpl相关的东西

SMPL原理

  • 先给出一个模板网格 T̄：手工制作的”标准人”网格，共 6890 个顶点、23 个关节，处于直立的零姿态（T-pose）。所有后续计算都是在这个模板上做加法。
  • 然后用：Bₛ(β) = Σ βₙ · Sₙ 定义高矮胖瘦，决定体型；
  • 用Bₚ(θ) = Σ (Rₙ(θ) − Rₙ(θ*)) · Pₙ 去给原模型修型，避免转动得到一系列问题
  • 叠加得到Tₚ(β, θ) = T̄ + Bₛ(β) + Bₚ(θ) 未摆姿势的模型
  • t’ᵢ = Σₖ wₖᵢ · G’ₖ(θ, J) · tₚᵢ得到蒙皮函数，其中 J为关节位置回归器（修正关节位置），wₖᵢ为蒙皮权重。
  • 最终得到三维人体网格。

在drivestudio中的应用

预处理

  • 第一步：project_human_boxes() — 把 3D bbox 投影到 2D 图像。给后面的 PHALP 提供”人在图像中哪个位置”的信息。
  • 第二步：run_4DHumans() — 逐相机运行 PHALP 追踪器。对每个相机使用HMR2模型将遮蔽的人体补全。得到体型与关节转向数据。
  • 第三步：match_and_postprocess() — 跨相机匹配 + 融合 + 插值

训练开始时

  • 构建 SMPL 模板，定义体型及修复，确定关节位置，确认蒙皮权重。
  • 构建高斯节点，通过顶点确定位置，法线确定方向，此时高斯在 canonical 空间（Da-pose），静止的

训练时

  • 提取当前可学习姿态，进行LBS变换，将坐标转为世界坐标，打包送给rasterizer
  • 公式为Gₕ_SMPL(t) = Tₕ(t) ⊗ LBS(θ(t), Ḡₕ_SMPL)，Tₕ(t)为世界空间， Ḡₕ_SMPL为高斯节点，θ(t)为关节角度。
