deepseek api monitor

Created2026-05-31|Updated2026-05-31
|Post Views:

  • 第一次尝试使用vibecoding，配置了Claude code，接的是deepseek的v4pro，用了一下午只花了两块，感谢梁圣开源，想试试这东西怎么样，就用他写了一个这个。

  • 工具地址

  • 因为deepseek的api检测不尽如人意，没法具体看到自己每次花了多少token，于是乎就让他写了这个东西，可以检测api使用情况。

  • 具体有两个方面：

    • 一个是ds的账户查询，最开始想做成挂着后台每分钟查询一次，用差值计算api使用情况，效果不是很好
    • 另一个就是找到电脑上Claude code的请求记录，直接计算token。

  • 把端口放到了3000，全程都在本地运行，不用担心key的暴露（大概）。

  • 使用的是我不是很熟悉的js，差一点把库扔到github上了，所以也没有仔细看每个部分是否合理，错误肯定是有的（output的计算可能有点问题，所以算的不是很准确，但能用）。
